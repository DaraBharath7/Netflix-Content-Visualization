## Project Overview

Netflix Content Visualization is a data analysis project that
explores Netflix movies and TV shows using Python.

The project uses data analysis and visualization techniques
to understand content distribution, genres, release years,
countries, ratings, and movie durations.

## Objectives

- Analyze the distribution of movies and TV shows.
- Identify the most common Netflix genres.
- Explore content production across countries.
- Analyze content ratings and movie durations.
- Examine Netflix titles by release year.
- Visualize when titles were added to Netflix.
- Create a dashboard summarizing key findings.

## Dataset

The project uses a Netflix Movies and TV Shows dataset
containing information about titles, directors, cast members,
countries, release years, ratings, durations, and genres.

The dataset is loaded directly into the notebook using Pandas.

## Methodology

1. Import the required Python libraries.
